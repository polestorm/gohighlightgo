# Wymagania: PlantUML

Źródło: PlantUML Language Reference Guide. Definicja: `highlight/lang/plantuml.hl`.

| Id | Wymaganie |
|---|---|
| LANG-2381 | Nazwy języka: `plantuml`, `puml`, `uml`. |
| LANG-2382 | Słowa z listy keyword (`@startuml`, `@enduml`, `participant`, `actor`, `boundary`, `control` …) dostają `hl-kw`. |
| LANG-2383 | Komentarze `'` do końca wiersza, `/' … '/` dostają `hl-com`; napisy `"…"` dostają `hl-str`. |
| LANG-2384 | Liczby dostają `hl-num`; znaki `->.:|*+#-<>=` dostają `hl-op`. |
