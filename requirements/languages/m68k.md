# Wymagania: Motorola 68000 assembly

Źródło: M68000 Family Programmer's Reference Manual (Motorola). Definicja: `highlight/lang/m68k.hl`.

| Id | Wymaganie |
|---|---|
| LANG-2671 | Nazwy języka: `m68k`, `asm68k`. |
| LANG-2672 | Słowa z listy keyword (`move`, `movea`, `moveq`, `movem`, `lea`, `pea` …) dostają `hl-kw`; słowa z listy builtin (`d0`, `d1`, `d2`, `d3`, `d4`, `d5` …) dostają `hl-builtin`; nazwa po `.` dostaje `hl-meta`; nazwa po `$` dostaje `hl-num` (bez rozróżniania wielkości liter). |
| LANG-2673 | Komentarze `;` do końca wiersza dostają `hl-com`; napisy `"…"`; `'…'` dostają `hl-str`. |
| LANG-2674 | Liczby dostają `hl-num`; znaki `#()+-*/,` dostają `hl-op`; konstrukcje haka `asm-label` jak w opisie haka w `docs/definitions.md`. |
