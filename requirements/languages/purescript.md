# Wymagania: PureScript

Źródło: PureScript language reference (documentation/language).

| Id | Wymaganie |
|---|---|
| LANG-1201 | Nazwy języka: `purescript`, `purs`. |
| LANG-1202 | Słowa kluczowe dostają `hl-kw`; typy i nazwy z wielkiej litery `hl-type`; `true false unit` i funkcje z listy `hl-builtin`; apostrof wewnątrz nazwy należy do nazwy. |
| LANG-1203 | Komentarz `--` i zagnieżdżany `{- … -}` dostają `hl-com`. |
| LANG-1204 | Napisy `"…"` i `"""…"""` oraz znak `'a'` dostają `hl-str`; liczby `hl-num`; operatory `hl-op`. |
