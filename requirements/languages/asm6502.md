# Wymagania: 6502 assembly

Źródło: MOS 6502 programming manual (MCS6500 Microcomputer Family Programming Manual). Definicja: `highlight/lang/asm6502.hl`.

| Id | Wymaganie |
|---|---|
| LANG-2661 | Nazwy języka: `asm6502`, `6502`, `ca65`. |
| LANG-2662 | Słowa z listy keyword (`lda`, `ldx`, `ldy`, `sta`, `stx`, `sty` …) dostają `hl-kw`; słowa z listy builtin (`a`, `x`, `y`) dostają `hl-builtin`; nazwa po `.` dostaje `hl-meta`; nazwa po `$` dostaje `hl-num`; nazwa po `%` dostaje `hl-num` (bez rozróżniania wielkości liter). |
| LANG-2663 | Komentarze `;` do końca wiersza dostają `hl-com`; napisy `"…"`; `'…'` dostają `hl-str`. |
| LANG-2664 | Liczby dostają `hl-num`; znaki `#<>+-*/(),=` dostają `hl-op`; konstrukcje haka `asm-label` jak w opisie haka w `docs/definitions.md`. |
