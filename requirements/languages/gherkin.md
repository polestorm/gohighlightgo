# Wymagania: Gherkin

Źródło: Cucumber documentation: Gherkin reference. Definicja: `highlight/lang/gherkin.hl`.

| Id | Wymaganie |
|---|---|
| LANG-1641 | Nazwy języka: `gherkin`, `cucumber`, `feature`. |
| LANG-1642 | Słowa z listy keyword (`Feature`, `Background`, `Scenario`, `Outline`, `Examples`, `Rule` …) dostają `hl-kw`; nazwa po `@` dostaje `hl-meta`. |
| LANG-1643 | Komentarze `#` do końca wiersza dostają `hl-com`; napisy `"""…"""` wielowierszowy; `"…"` dostają `hl-str`. |
| LANG-1644 | Liczby dostają `hl-num`; znaki `|:*` dostają `hl-op`. |
