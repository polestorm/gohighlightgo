# Wymagania: ActionScript 3

Źródło: ActionScript 3.0 Language Reference (Adobe).

| Id | Wymaganie |
|---|---|
| LANG-1121 | Nazwy języka: `actionscript`, `as3`, `actionscript3`. |
| LANG-1122 | Wszystko jak w JavaScripcie (`LANG-042`–`LANG-048`), a dodatkowo słowa ActionScriptu (`package`, `internal`, `override`, `dynamic` …) dostają `hl-kw`, a typy (`int`, `uint`, `Number`, `Vector` …) `hl-type`. |
