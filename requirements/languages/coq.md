# Wymagania: Coq (Rocq)

Źródło: The Coq Reference Manual (8.19): polecenia, termy, taktyki.

| Id | Wymaganie |
|---|---|
| LANG-1231 | Nazwy języka: `coq`, `rocq`, `v-coq`. |
| LANG-1232 | Polecenia (`Definition`, `Theorem`, `Proof`, `Qed` …) i słowa termów (`forall`, `fun`, `match` …) dostają `hl-kw`; sorty i typy z listy `hl-type`; taktyki z listy `hl-builtin`. |
| LANG-1233 | Komentarz `(* … *)`, który się zagnieżdża, dostaje `hl-com`. |
| LANG-1234 | Napis `"…"` z `""` dostaje `hl-str`; liczby `hl-num`; operatory `hl-op`. |
