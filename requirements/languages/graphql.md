# Wymagania: GraphQL

Źródło: GraphQL Specification (October 2021), rozdział 2 „Language”.

| Id | Wymaganie |
|---|---|
| LANG-491 | Nazwy języka: `graphql`, `gql`. |
| LANG-492 | Słowa kluczowe dostają `hl-kw`; typy skalarne i nazwy z wielkiej litery `hl-type`; `true false null` `hl-builtin`. |
| LANG-493 | Komentarz `#` do końca wiersza dostaje `hl-com`. |
| LANG-494 | Napis `"…"` i napis blokowy `"""…"""` dostają `hl-str`; zmienna `$nazwa` `hl-attr`; dyrektywa `@nazwa` `hl-meta`; liczby `hl-num`. |
