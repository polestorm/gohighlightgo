# Wymagania: Vala

Źródło: Vala Reference Manual: lexical structure. Definicja: `highlight/lang/vala.hl`.

| Id | Wymaganie |
|---|---|
| LANG-1511 | Nazwy języka: `vala`, `vapi`. |
| LANG-1512 | Słowa kluczowe dostają `hl-kw`; typy podstawowe `hl-type`; `true false null this base print` `hl-builtin`; dyrektywy `#if` jak w C. |
| LANG-1513 | Komentarze `//` i `/* … */` dostają `hl-com`; napisy `"…"`, dosłowne `"""…"""` i szablony `@"…$x…"` oraz znaki `'…'` `hl-str`; liczby `hl-num`; nazwa przed `(` `hl-fn`. |
