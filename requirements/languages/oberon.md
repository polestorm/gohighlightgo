# Wymagania: Oberon

Źródło: N. Wirth, „The Programming Language Oberon” (Oberon-07, wersja z 2016). Definicja: `highlight/lang/oberon.hl`.

| Id | Wymaganie |
|---|---|
| LANG-751 | Nazwy języka: `oberon`, `ob`, `obn`. |
| LANG-752 | Słowa zastrzeżone dostają `hl-kw`; typy podstawowe `hl-type`; procedury predeklarowane `hl-builtin`. |
| LANG-753 | Komentarz `(* … *)`, który się zagnieżdża, dostaje `hl-com`. |
| LANG-754 | Napis `"…"` dostaje `hl-str`; liczby `hl-num`; operatory `hl-op`; nazwa przed `(` `hl-fn`. |
