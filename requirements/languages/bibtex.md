# Wymagania: BibTeX

Źródło: BibTeXing (O. Patashnik) and the biblatex documentation: entry syntax. Definicja: `highlight/lang/bibtex.hl`.

| Id | Wymaganie |
|---|---|
| LANG-1571 | Nazwy języka: `bibtex`, `bib`, `biblatex`. |
| LANG-1572 | Nazwa po `@` dostaje `hl-kw`; nazwa przed `=` dostaje `hl-attr`. |
| LANG-1573 | napisy `"…"` z ucieczkami `hl-esc` dostają `hl-str`. |
| LANG-1574 | Liczby dostają `hl-num`; znaki `=#,` dostają `hl-op`. |
