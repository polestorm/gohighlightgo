# Wymagania: Hack

Źródło: Hack documentation (docs.hhvm.com/hack). Definicja: `highlight/lang/hack.hl`.

| Id | Wymaganie |
|---|---|
| LANG-1351 | Nazwy języka: `hack`, `hh`. |
| LANG-1352 | Wszystko jak w PHP (`LANG-262`–`LANG-265`), a dodatkowo słowa Hacka (`async`, `await`, `newtype`, `enum` …) dostają `hl-kw`, a typy (`vec`, `dict`, `keyset`, `shape` …) `hl-type`. |
