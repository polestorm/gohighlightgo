# Wymagania: PL/SQL

Źródło: Oracle Database PL/SQL Language Reference (23ai). Definicja: `highlight/lang/plsql.hl`.

| Id | Wymaganie |
|---|---|
| LANG-831 | Nazwy języka: `plsql`, `pls`. |
| LANG-832 | Wszystko jak w SQL (`LANG-082`–`LANG-085`), a dodatkowo słowa bloków PL/SQL (`DECLARE`, `EXCEPTION`, `LOOP`, `CURSOR`, `ELSIF` …) dostają `hl-kw`, typy Oracle (`VARCHAR2`, `NUMBER`, `PLS_INTEGER` …) `hl-type`, a funkcje z listy `hl-builtin`. |
