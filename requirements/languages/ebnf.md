# Wymagania: EBNF

Źródło: ISO/IEC 14977:1996 (Extended BNF). Definicja: `highlight/lang/ebnf.hl`.

| Id | Wymaganie |
|---|---|
| LANG-1891 | Nazwy języka: `ebnf`. |
| LANG-1892 | Komentarze `(* … *)` dostają `hl-com`; napisy `"…"`; `'…'` dostają `hl-str`. |
| LANG-1893 | Liczby dostają `hl-num`; znaki `=|,;[]{}()-*?` dostają `hl-op`. |
