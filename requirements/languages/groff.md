# Wymagania: roff (man pages)

Źródło: groff(7) and man(7) manual pages. Definicja: `highlight/lang/groff.hl`.

| Id | Wymaganie |
|---|---|
| LANG-2491 | Nazwy języka: `groff`, `roff`, `troff`, `man`, `nroff`. |
| LANG-2492 | Nazwa po `.` dostaje `hl-kw`. |
| LANG-2493 | Komentarze `.\"` do końca wiersza, `\"` do końca wiersza dostają `hl-com`; napisy `"…"` dostają `hl-str`. |
| LANG-2494 | Liczby dostają `hl-num`; znaki `\` dostają `hl-op`. |
