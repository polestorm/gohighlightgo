# Wymagania: Z80 assembly

Źródło: Zilog Z80 CPU User Manual (UM0080) instruction set. Definicja: `highlight/lang/z80.hl`.

| Id | Wymaganie |
|---|---|
| LANG-2111 | Nazwy języka: `z80`, `z80asm`. |
| LANG-2112 | Słowa z listy keyword (`ld`, `ldi`, `ldir`, `push`, `pop`, `ex` …) dostają `hl-kw`; słowa z listy builtin (`a`, `b`, `c`, `d`, `e`, `h` …) dostają `hl-builtin`; nazwa po `.` dostaje `hl-meta`; nazwa po `$` dostaje `hl-num` (bez rozróżniania wielkości liter). |
| LANG-2113 | Komentarze `;` do końca wiersza dostają `hl-com`; napisy `"…"` z ucieczkami `hl-esc`; `'…'` dostają `hl-str`. |
| LANG-2114 | Liczby dostają `hl-num`; znaki `+-*/(),#` dostają `hl-op`; konstrukcje haka `asm-label` jak w opisie haka w `docs/definitions.md`. |
