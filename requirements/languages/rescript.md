# Wymagania: ReScript

Źródło: ReScript language manual (v11).

| Id | Wymaganie |
|---|---|
| LANG-1211 | Nazwy języka: `rescript`, `res`, `resi`. |
| LANG-1212 | Słowa kluczowe dostają `hl-kw`; typy podstawowe i nazwy z wielkiej litery (moduły, konstruktory) `hl-type`; `true false None Some Ok Error` `hl-builtin`; dekorator `@nazwa` `hl-meta`. |
| LANG-1213 | Komentarze `//` i `/* … */` dostają `hl-com`. |
| LANG-1214 | Napis `"…"` i szablon `` `…` `` ze wstawkami `${…}` dostają `hl-str`; liczby `hl-num`; nazwa przed `(` `hl-fn`. |
