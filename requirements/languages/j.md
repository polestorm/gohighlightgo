# Wymagania: J

Źródło: J NuVoc (jsoftware.com): control words, komentarze. Definicja: `highlight/lang/j.hl`.

| Id | Wymaganie |
|---|---|
| LANG-1361 | Nazwy języka: `j`, `ijs`. |
| LANG-1362 | Słowa sterujące z kropką (`if.`, `do.`, `end.`, `while.` …) dostają `hl-kw`; nazwa może zawierać `.`, `:`, `_`. |
| LANG-1363 | Komentarz `NB.` do końca wiersza dostaje `hl-com`; napis `'…'` z `''` `hl-str`; liczby `hl-num`; prymitywy (znaki interpunkcji) `hl-op`. |
