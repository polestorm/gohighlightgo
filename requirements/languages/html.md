# Wymagania: HTML

Źródło: HTML Living Standard, rozdział 13 „The HTML syntax”.

| Id | Wymaganie |
|---|---|
| LANG-121 | Nazwy języka: `html`, `htm`, `xhtml`. |
| LANG-122 | Znaczniki, atrybuty, wartości (także bez cudzysłowu: `hl-str`), odwołania znakowe, komentarze i `<!DOCTYPE html>` jak w XML (`LANG-112`–`LANG-115`). |
| LANG-123 | Treść elementu `<script>` aż do `</script` (bez względu na wielkość liter) jest kolorowana jak JavaScript, a treść `<style>` aż do `</style` jak CSS (13.1.2.1, „raw text elements”). Napis albo komentarz niezamknięty w tej treści kończy się na znaczniku zamykającym. |
