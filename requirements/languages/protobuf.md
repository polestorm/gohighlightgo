# Wymagania: Protocol Buffers

Źródło: Protocol Buffers Version 3 Language Specification i „Editions”.

| Id | Wymaganie |
|---|---|
| LANG-481 | Nazwy języka: `protobuf`, `proto`, `proto3`. |
| LANG-482 | Słowa kluczowe dostają `hl-kw`; typy skalarne `hl-type`, a nazwy z wielkiej litery (wiadomości, wyliczenia) też `hl-type`; `true false inf nan` `hl-builtin`. |
| LANG-483 | Komentarze `//` i `/* … */` dostają `hl-com`. |
| LANG-484 | Napisy `"…"` i `'…'` z ucieczkami dostają `hl-str`; liczby `hl-num`; `=` `hl-op`. |
