# Wymagania: BNF

Źródło: the Backus–Naur form as used in RFC 5234 (ABNF) and the ALGOL 60 report. Definicja: `highlight/lang/bnf.hl`.

| Id | Wymaganie |
|---|---|
| LANG-1881 | Nazwy języka: `bnf`, `abnf`. |
| LANG-1882 | napisy `"…"`; `<…>` dostają `hl-str`. |
| LANG-1883 | Liczby dostają `hl-num`; znaki `::=|/*()[]` dostają `hl-op`. |
