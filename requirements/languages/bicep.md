# Wymagania: Bicep

Źródło: dokumentacja Bicep (Azure): struktura pliku, składnia, typy danych.

| Id | Wymaganie |
|---|---|
| LANG-1041 | Nazwa języka: `bicep`. |
| LANG-1042 | Słowa kluczowe dostają `hl-kw`; typy `hl-type`; `true false null` i funkcje z listy `hl-builtin`; dekorator `@nazwa` `hl-meta`. |
| LANG-1043 | Komentarze `//` i `/* … */` dostają `hl-com`. |
| LANG-1044 | Napis `'…'` ze wstawkami `${…}` i wielowierszowy `'''…'''` dostają `hl-str`; liczby `hl-num`; nazwa przed `(` `hl-fn`. |
